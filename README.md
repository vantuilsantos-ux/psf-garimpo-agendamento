# 🏥 Transformação Digital e Otimização do Acesso à Saúde: PSF Garimpo de Capoeirana

Este repositório contém a aplicação web desenvolvida para a automação do agendamento de consultas no **Posto de Saúde da Família (PSF) Garimpo de Capoeirana**, desenvolvida no âmbito da disciplina **Projeto Integrador de TI II**.

---

## 📌 Sobre o Projeto

A plataforma substitui as tradicionais filas presenciais de madrugada por um sistema digital responsivo e acessível. A interface foi projetada com foco em moradores com baixa literacia digital, utilizando navegação simplificada por ícones e componentes reativos.

---

## 🛠️ Tecnologias Utilizadas

- **Framework Web:** React.js
- **Marcação e Estilização:** HTML5 Semântico e CSS3 (Flexbox, Grid, Media Queries)
- **Acessibilidade:** Diretrizes WCAG e marcações ARIA
- **Design:** Abordagem Mobile-First
